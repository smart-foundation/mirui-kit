MiSans UI typeface (小米 MiSans) — free for commercial use.

The file `misans_ui.mirx` is the MiSans UI typeface packaged inside mirui's MIRX
binary asset container. It was taken from the mirui crate's bundled gallery
assets (mirui is MIT licensed) and is redistributed here for use by this
example.

MiSans is published by Xiaomi Corporation under the MiSans typeface licence,
which grants free use including commercial use, modification and redistribution
with the font files.

Upstream: https://hyperos.mi.com/font/en/

If you replace this asset with a font of your own, keep the matching licence
file in this directory.
